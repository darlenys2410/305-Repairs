# 305 Equipment Repair - App de Reparaciones

App para registrar y fotografiar reparaciones de equipos. Disponible en español e inglés.

## 🚀 Instalación en iPhone

1. Abre este sitio en Safari
2. Toca el botón ⬆️ en la esquina superior derecha
3. Desplázate hacia abajo
4. Toca "Agregar a pantalla de inicio"
5. Elige un nombre y toca "Agregar"

¡El app aparecerá en tu pantalla de inicio! 📱

## 📁 Archivos

- `index.html` - Versión en español (por defecto)
- `en.html` - Versión en inglés
- `manifest.json` - Configuración de PWA

## 🌐 Idiomas

Ambas versiones tienen un botón 🌐 para cambiar entre español e inglés.
